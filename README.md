# THE-BENGAL-KNIGHT-SONARGAON-
It is a 3D adventure game blending history, culture, and storytelling to promote Bangladeshi heritage. Designed character mechanics and gameplay narrative around historical figures (Baro Bhuiyans). Utilized Unity 3D and C#, incorporating. Demonstrated leadership and creativity in managing art, code, and story integration.
